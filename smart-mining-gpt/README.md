# معدن‌بان — نسخه آزمایشی GPT

داشبورد راست‌به‌چپ مدیریت معدن با React + TypeScript + Vite.

## اجرا

```bash
npm install
npm run dev
```

برای ساخت خروجی قابل انتشار:

```bash
npm run build
```

## امکانات نمونه
- داشبورد مدیریتی، KPI، نمودار تولید و نمودار ترکیب فعالیت‌ها
- ماژول‌های استخراج، حفاری و آتشباری، ناوگان، ایمنی، مجوزها و گزارش‌ها
- ثبت و حذف رخدادها و جست‌وجو در جدول عملیات
- ذخیره محلی داده‌های نمونه در مرورگر (localStorage)
- خروجی CSV جدول عملیات

**هشدار:** اطلاعات تولید و مبالغ تماما نمایشی هستند. این نسخه احراز هویت و پایگاه داده سروری ندارد و برای ثبت اطلاعات محرمانه یا عملیات حساس معدن مناسب نیست. تصمیمات آتشباری و ایمنی نیاز به تایید مهندس صلاحیت‌دار و الزامات قانونی دارند.

## انتشار
کدها را در مخزن خصوصی GitHub قرار دهید. برای استقرار واقعی از سرویس میزبانی مناسب با احراز هویت و پایگاه داده استفاده کنید. در صورت ساخت نسخه استاتیک می‌توانید `dist` را روی GitHub Pages منتشر کنید ولی اطلاعات محرمانه در آن وارد نکنید.
